Tether Wallet: Digital Dollars, Gold and Bitcoin in One Wallet

Tether Wallet is a self-custodial digital wallet designed for USD₮, USA₮, XAU₮ and Bitcoin. It combines multi-network transfers, Tether.me usernames, transaction tracking and wallet backup options in a single interface.

What Is Tether Wallet?

Tether Wallet is a digital wallet built around self-custody. It lets users store, send and receive supported digital assets while keeping control of the wallet on their own device.

The application is designed to simplify digital-asset transfers by presenting compatible networks and balances without requiring users to manage every technical blockchain detail.

Tether describes the wallet as self-custodial, with transactions signed directly on the user's device before being broadcast to the blockchain.

Self-Custodial by Design

Tether Wallet is designed as a self-custodial application. Transactions are signed locally on the user's device before being sent to the blockchain.

Tether's wallet information states that Tether cannot access or move a user's funds through the wallet, and private keys and recovery information are not available to Tether in readable form.

Local Transaction Approval

Each transaction requires user approval, with the signing process taking place on the device.

The 12-Word Recovery Phrase

A new Tether Wallet generates a 12-word recovery phrase. It can be used to restore wallet access when necessary.

Tether states that the recovery phrase is created on the device and is not sent to Tether in readable form.

Cloud Backup

The wallet provides an encrypted cloud-backup option. Wallet data is encrypted on the device, while the encryption key is stored separately in the user's personal cloud account.

Manual Backup

Users can also keep their 12-word recovery phrase manually instead of using cloud backup.

Tether.me Username

Tether Wallet includes a human-readable Tether.me username for supported transfers. This can reduce the need to copy long blockchain addresses when sending between compatible users.

Traditional blockchain addresses and QR codes remain available for external wallet transfers.

Sending Digital Assets

The Send function lets users select a supported asset, choose an available network, enter an amount and review the transaction before approval.

Users can send through a Tether.me username, a blockchain address or a QR code. The wallet displays transaction information before confirmation.

Network Selection

The wallet shows compatible networks for the selected asset, helping separate the user experience from the technical details of individual blockchains.

Receiving Tokens

Users can receive through a Tether.me username or through a blockchain address and QR code. For blockchain transfers, the user selects the relevant token and network before sharing the displayed receiving information.

Transaction Fees

Tether Wallet states that it does not charge a separate wallet fee for sending or receiving. Blockchain transactions can still involve network fees required to process a transfer.

The application displays relevant fee information before the user approves a transaction.

Send Max

When Send Max is used, the network fee is deducted from the amount being sent, so the recipient may receive slightly less than the sender's full balance.

Asset and Balance Tracking

The wallet provides a total wallet balance and an asset breakdown. Opening an individual asset can show holdings, market value, chain distribution, addresses and recent transactions.

Transaction details can be opened to review what arrived, when it arrived and where it came from.

Bitcoin and Lightning

Bitcoin is supported through the Bitcoin blockchain and Bitcoin Lightning. Lightning provides a separate payment rail for Bitcoin transfers.

Tether's support documentation also notes BOLT11 invoices and LNURL for Bitcoin Lightning transfers.

Tether Wallet and WDK

Tether announced Tether Wallet as part of its broader wallet infrastructure built on the open-source Wallet Development Kit, known as WDK by Tether.

WDK is designed as infrastructure for building self-custodial digital-asset wallets, while Tether Wallet provides an end-user application built around this wallet technology.

Everyday Digital-Asset Transfers

Tether Wallet is positioned around everyday transfers of digital dollars, gold and Bitcoin. Its combination of supported assets, multiple networks and human-readable usernames is designed to make routine wallet activity easier to manage.

The interface keeps much of the underlying blockchain complexity in the background while users work with balances, recipients, networks and transaction information.
